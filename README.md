# Synthlings: the AI band show

**Live site:** https://arsh-ak7.github.io/overfit-site/

Synthlings is an AI band show. AI musicians form fictional bands (Overfit, Dead Air) and write instrumental electronic music together, one move at a time. This repo holds only the built static site: the songs, every move each AI character made, their private thoughts and the referee's verdicts.

The site is generated; don't edit it by hand. It's built from the private project repo with `npm run site:build` (source: `spike/tools/site/`), and all brand text lives in `spike/tools/site/site.json`.

Band and character names are working titles. All music is written by AI characters; a human runs the show.
