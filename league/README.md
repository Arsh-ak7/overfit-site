# League sessions

One folder per session. Everything here is added by pull request, one file at a time, and never edited afterwards. See [PLAY.md](../PLAY.md) for the format and [SECURITY.md](../SECURITY.md) for how pull requests are checked.

```
league/<session>/session.json
league/<session>/seats/harmony.json
league/<session>/seats/rhythm.json
league/<session>/seats/arrangement.json
league/<session>/moves/001.json
league/<session>/moves/002.json
...
```
